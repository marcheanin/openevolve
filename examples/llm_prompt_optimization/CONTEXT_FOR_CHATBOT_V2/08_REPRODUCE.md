# Как всё пересчитать

Корень проекта:
`openevolve/examples/llm_prompt_optimization/prime_v2_group_robust/`

## Одна команда

```
python scripts/run_s11_final.py
```

Запускает 15 анализов, пишет полный вывод каждого в
`results/S11_protocol_matrix/final/`, занимает **4.7 минуты** и **не обращается
к API**. Отказывается считать, если матрица предсказаний неполна; с
`--allow-partial` считает и штампует каждый файл пометкой «не для цитирования».

## Данные

| путь | что |
|---|---|
| `results/S11_protocol_matrix/fixed_sets/truth_large.json` | тест: строки, метки, группы, фингерпринт `306d7a977265` |
| `results/S11_protocol_matrix/fixed_sets/dev_universe.json` | валидация: фингерпринт `178439a57046` |
| `results/S11_protocol_matrix/preds/truth_large/*.npy` | 37 векторов предсказаний по 3600 |
| `results/S11_protocol_matrix/preds/dev_universe/*.npy` | 37 векторов по 4325 |
| `results/S11_protocol_matrix/power_summary.json` | таблица мощности с Холмом |
| `results/S11_protocol_matrix/lottery_summary_*.json` | шесть сводок лотереи |

Файлы с префиксом `_` (например `_seed_rescore.npy`) — служебные, исключаются
всеми анализами. Значение `−1` в векторе предсказаний означает «ответ не удалось
разобрать в метку».

## Скрипты

| скрипт | отвечает на |
|---|---|
| `build_s11_sets.py` | сборка обоих фиксированных множеств из официальных сплитов |
| `score_s11_matrix.py` | скоринг матрицы (единственный, кому нужен API) |
| `analyze_s11.py --part power` | разрешающая способность, поправка Холма, масштабирование |
| `analyze_s11.py --part lottery` | протокольная лотерея; флаги `--target`, `--pool`, `--draws` |
| `gate_a_recheck.py` | перепроверка прежней декомпозиции на старом кэше; опыт со сжатым пулом |
| `draw_lottery_check.py` | лотерея розыгрыша тестовой выборки |
| `ci_calibration_check.py` | покрытие интервала расщеплением пополам |
| `statistic_reproducibility.py` | сравнение статистик; `--sweep` по весу сжатия, `--faithfulness` |
| `repeats_vs_rows.py` | повторы скоринга против строк |
| `pool_spread_check.py` | разброс пула с поправкой на шум |
| `run_s11_final.py` | драйвер всего перечисленного |

## Главный рабочий документ

`experiments/S11_protocol_study/PLAN_AND_FINDINGS.md` — около 900 строк,
десять разделов результатов, полная хронология с пометками о том, что было
переписано и почему. Настоящая папка — выжимка из него для внешнего читателя.

## Конфигурация скоринга

Скорер `google/gemma-3-12b-it` через OpenRouter при T≈0, один проход на строку
(повторы проверены и не окупаются, см. `04_RESULTS.md` раздел 7).
Параллельность 4 (измеренный потолок: при 16 провайдер отдавал 78% ошибок 429).
Режим `fail_closed`: неразобранный ответ считается ошибкой при скоринге, но
**исключается** из метрик анализа.

Полная стоимость сбора матрицы — около **$8.3**.
