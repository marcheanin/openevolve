## Чем продолжить

**Сначала убрать файл-флаг, иначе прогон остановится сразу же:**

```
rm results/S15_toxlang_matrix/scorer_gemma/STOP
```

Затем та же команда, что шла до паузы (она дописывает по длине массивов, уже посчитанное не
пересчитывается):

```
PYTHONIOENCODING=utf-8 nohup python scripts/score_s11_scorer2.py \
  --tag gemma --model google/gemma-3-12b-it --no-logprobs \
  --config experiments/S15_toxlang/config_toxlang.yaml \
  --sets-dir results/S15_toxlang_matrix/fixed_sets \
  --out-root results/S15_toxlang_matrix/scorer_gemma \
  --prompts-json results/S15_toxlang_matrix/prompts.json \
  --plan truth_tox:1000,truth_tox:3000 \
  --max-spend 1.5 --chunk 120 --max-parallel 12 \
  >> results/S15_toxlang_matrix/prespend_p12.log 2>&1 &
```

`--max-parallel 12` важно: при 6 темп был 0,44 строк/с, при 12 — 5,8 строк/с по медиане
последних блоков, и повторы перестали накапливаться. При 3 и при закреплённом провайдере было
хуже всего (см. `CONSTRUCTION_NOTES.md` §8).

## Что делать после того, как блок досчитает

Порядок из предрегистрации, шаги 3–6:

1. **Доля неразобранных по каждому языку.** Если на каком-то языке она заметно выше — записать;
   строки выбрасываются для всех промптов сразу и утоньшают ячейку именно этой группы.
2. **Правило пола.** Если у стартового промпта `GBA_g < 0,55` для какого-то языка — заменить его
   на следующий из резерва `it, es, uk, zh, ja` и отчитаться отдельной строкой.
3. **Посчитать** `R` (полуширина), `H` (запас по порогу), `L` (рычаг порога), `k`, и `C95(12)`
   скриптом `best_of_n_ceiling.py` с `S11_DATASET=toxlang`.
4. **Второй хэш:** записать эти числа и вытекающий из них вердикт в `PRESPEND_S15.md` и
   захэшировать **до** запуска живой петли. После этого числа не правятся.
5. **Живая петля:** `python scripts/run_s12_live_loop.py --dataset toxlang --methods
   ape,apo,evoprompt_de,gepa --protocols hard_min --seeds 42,43,44 --max-parallel 12`.
6. **Финалы на тесте** тем же скорером, затем анализ и `RESULTS_S15.md` с ответом по каждому из
   шести предсказаний H-S1…H-S6.

## Чем продолжить живую петлю

```
rm results/S15_toxlang_loop/STOP

PYTHONIOENCODING=utf-8 nohup python scripts/run_s12_live_loop.py \
  --dataset toxlang \
  --config experiments/S15_toxlang/config_toxlang.yaml \
  --methods ape,apo,evoprompt_de,gepa \
  --protocols hard_min \
  --seeds 42,43,44 \
  --max-parallel 12 \
  --max-spend 15.0 \
  >> results/S15_toxlang_loop_run.log 2>&1 &
```

Готовые прогоны пропускаются по наличию `done.json`, пересчитываться не будут.
Осталось 10 прогонов: прогноз около **13,5 часов** и **$4,0**.

`--config experiments/S15_toxlang/config_toxlang.yaml` обязателен: без него берётся общий конфиг
с `max_retries: 5`, на котором троттлинг DeepInfra съедал 12,5 % строк в неразобранные.

## Как приостановить в следующий раз

```
touch results/S15_toxlang_matrix/scorer_gemma/STOP
```

Процесс выйдет между блоками сам, напечатав `[pause]`. Убивать процесс не нужно: возобновление
идёт по длине сохранённых массивов, но незаконченный блок при убийстве теряется, а при флаге —
нет.
