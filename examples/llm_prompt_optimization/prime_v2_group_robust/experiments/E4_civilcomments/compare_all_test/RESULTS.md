### Amazon E6 observations

- **GPO improves the primary robust metric** vs seed: 0.432 -> **0.458** (`+0.026`).
- A one-line harshness edit (`deflate_positive`) reaches the **same primary score as GPO**,
  so search gains are still partly confounded with operating-point movement.
- F9 replication succeeds on Amazon too: targeted `d_dev` cuts selection regret
  **0.025 -> 0.007** with the same total dev budget.
- Unlike CivilComments E5, `hard_min` on uniform `d_dev` is **not** anti-correlated here
  (Spearman `+0.40` vs test cvar25), while `R_global` is a poor selector (`-0.16`).
- EvoPrompt-DE and final PRIME `test_fixed` scoring were blocked by OpenRouter 403 key limit,
